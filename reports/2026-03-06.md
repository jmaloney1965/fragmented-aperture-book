## Figure Extraction
Used established workflow: `pdftoppm -png -r 300` -> Python PIL crop -> visual verification -> LaTeX placement. Extracted figures from 8 papers total across Ch 9 and Ch 10.

### Lessons Learned — Figure Extraction
- **pdftoppm suffix convention**: Output files use the actual page number as suffix (e.g., `page4-4.png` for page 4), not sequential numbering. Always `ls` the output to check actual filenames.
- **Always use absolute paths** in Python PIL scripts — relative paths fail silently or error out.
- **Verify figure page numbers** in papers before cropping. Figure numbers don't always correspond to expected pages (e.g., Zhao2015 Fig 5 and Fig 6 were both on page 3, not pages 4-5).
- **Check full figure extent** before setting crop bounds. Multi-part figures (like Gomez2025 Fig 1 with (a) schematic and (b) photo) can be taller than expected.

### Lessons Learned — Cross-Reference Audit
- **Use `encoding='latin-1'`** when reading .tex files in Python — some contain non-UTF-8 characters (e.g., multiplication sign x as byte 0xd7).
- **Fuzzy matching by first 8 chars** is decent but misses cases where cite key and filename diverge (e.g., `Lee2023UWBAbsorber` vs `Lee2023_UWB_Pixelated_Absorber.pdf`). A more robust approach would normalize both sides more aggressively.

### General Lessons
- **El Badawe papers**: Metasurfaces but NOT pixelated/fragmented — don't belong in Ch 10. Always verify that a paper uses binary pixel optimization before including.
- **Parallel agent reading** of papers works well for extracting figure candidates from multiple papers simultaneously.
