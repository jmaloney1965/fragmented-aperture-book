### Then: built the PDF on the M4 (xelatex) — uncovered 4 issues

The book had never been built from this M4 before. xelatex lives at
`~/Library/TinyTeX/bin/universal-darwin/` (not on PATH by default; the user
prepends it manually). Found via prior-session reference.

Issues hit and resolved:

1. **`\pdfminorversion=7` at topLevel.tex:1** — pdftex-only primitive,
   xelatex errors immediately. Guarded with `\ifdefined…\fi` (commit `3d1ce7c`).
2. **`tocloft` not installed** — `tlmgr install tocloft` (sandbox-blocked,
   needed `dangerouslyDisableSandbox: true`).
3. **`\toprule` / `[H]` undefined** — `\usepackage{booktabs}` and
   `\usepackage{float}` missing from preamble. App B's `874bb09` sections use
   both but never loaded the packages. Added (commit `3d1ce7c`).
4. **3 appendixB figures referenced without `appendixB/` prefix** —
   inconsistent with all other App B figures. Fixed (commit `3d1ce7c`).

### Remaining warnings (non-blocking)
- Font shape `TU/ptm/*` undefined — `\usepackage{times}` is legacy pdftex
  and doesn't ship Unicode shapes for xelatex. xelatex falls back to its
  default font. If we want true Times across xelatex builds, switch to
  `\usepackage{fontspec}\setmainfont{Times New Roman}`.
- Many undefined `\cite{...}` warnings (e.g. `MaloneyKeslerHarms`,
  `Pringle2004Reconfigurable`) — the manual `\thebibliography` block
  doesn't have matching `\bibitem` entries for everything cited. Shows as
  `[?]` in the PDF. Out of scope for this session.
